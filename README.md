# Relay Bridge

A local [MCP](https://modelcontextprotocol.io) server that lets Claude Code delegate real repository work —
analysis, implementation, tests, commits, branches — to other AI coding agents, starting with Gemini through the
Google Antigravity CLI.

> Work in progress. The server is being built in the first feature pull request; this README describes it once it
> lands. The contribution flow is in [CONTRIBUTING.md](CONTRIBUTING.md).
